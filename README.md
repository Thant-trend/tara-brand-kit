# Tara brand kit

Brand kit and sample UI for the Tara event-ticketing app: logo, app icons, colour, type, components, six screens and developer tokens.

## What's here

| File | What it is |
| --- | --- |
| `index.html` | The web kit. Icon downloads (SVG, PNG, zip) and token copy/download work here. |
| `tara-brand-kit.pdf` | Static 12-page showcase PDF for sharing. |
| `tara-brand-kit-print.html` | Print layout the PDF is made from. Open in Chrome and print for brand-accurate fonts. |
| `tara-app-icons.zip` | Pre-built icon pack: SVG, PNG sizes, iOS, Android adaptive layers, web favicons. |
| `tara-logo.svg` | The logo. |
| `vercel.json` | Hosting config: clean URLs, noindex, zip downloads. |

## Deploy

Static site, no build step. In Vercel: **Add New → Project → import this repo**, then:

- Framework preset: **Other**
- Build command: leave empty
- Output directory: leave empty (the repo root is served)

## Brand basics

- Gradient `#7FE9F5 → #4DF59A → #D4FF1F` at 135°, ink `#0A0A0A`, lilac `#C9B6FF` as a 5% accent.
- Text on any brand colour is always ink.
- Fonts: Plus Jakarta Sans, Inter, JetBrains Mono (loaded from Google Fonts).
